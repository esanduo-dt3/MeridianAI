# Artifacts

This section holds the generated artifacts produced while planning and executing work on MeridianAI. They are records of a point in time: an audit describes the codebase as it stood when the audit ran, and a plan describes intended work together with the status of each step. They are not reference documentation for current behavior, which lives in [Architecture](../Architecture/index.md).
